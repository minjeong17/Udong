# API(Application Programming Interface)란?

## 개요
**API**는 서로 다른 소프트웨어 시스템 또는 애플리케이션이 데이터를 주고받고, 기능을 이용할 수 있도록 규칙과 구조를 표준화한 인터페이스입니다.  
- 프로그램, 서비스, 모듈이 내부 구조를 공개하지 않고 소통 가능  
- 현대 개발 환경에서 소프트웨어 확장성과 통합의 핵심 도구

---

## 특징 및 장점
- **중개자 역할**: 클라이언트와 서버 사이에서 데이터와 기능을 안전하게 전달
- **캡슐화**: 내부 동작을 숨기고 필요한 기능만 외부에 공개 (보안 및 유지보수 쉬움)
- **표준화**: 플랫폼에 상관없이 재사용과 호환 용이
- **생태계 확장**: 외부 및 파트너사가 새 서비스나 애플리케이션 개발 가능
- **자동화 및 통합**: 반복 업무 자동화, 다양한 시스템 연동에 효과적

---

## 동작 구조
1. **요청(Request)**: 클라이언트가 데이터 명령이나 기능 요청
2. **처리(Process)**: 서버 혹은 API 제공자가 요청을 검증하고 실행
3. **응답(Response)**: 요청 결과(데이터, 상태 코드 등)를 반환

- 예시:  
  `GET /weather?city=Seoul`  
  → 서울 날씨 정보를 JSON 형태로 반환

---

## 주요 API 종류

| 종류           | 특성/표준                 | 활용 예시            |
| -------------- | ------------------------ | ------------------- |
| REST API       | HTTP 기반, 포맷 다양      | SNS, 웹·모바일 연동 |
| SOAP API       | XML, 높은 보안, 무거움    | 금융, 기관 계정/결제 |
| GraphQL API    | 쿼리 언어, 효율적 데이터 | Facebook, GitHub    |
| gRPC API       | Google, 고성능            | 마이크로서비스      |
| WebSocket API  | 실시간 양방향 통신 지원   | 채팅, 게임, 주식    |

---

## 접근 방식 분류

- **공개(Open) API**: 누구나 사용 가능  
- **파트너(Partner) API**: 제한된 협력사 사용  
- **내부(Internal) API**: 조직 내 시스템 간 통신  
- **복합(Composite) API**: 여러 API 일괄 호출/처리

---

## 실전 활용 예시
- 지도 API: Google, Kakao, Naver
- 결제 API: PayPal, 네이버페이, 카카오페이
- SNS API: Facebook, Twitter, Instagram
- 공공데이터 API: 정부, 지자체 등 공공기관
- 클라우드 API: AWS, GCP, Azure

---

> **API**는 소프트웨어 확장성, 자동화, 시스템 통합 실현에 필수이며, 혁신적인 서비스 개발과 효율적인 운영을 위한 핵심 인프라입니다.
