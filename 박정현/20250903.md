### 3.3 타입 별칭 vs 인터페이스
- 둘 다 객체의 “모양”을 정의.  
- `interface`는 선언 병합 가능, `type`은 유니온/교차 등 타입 조합이 유연.

```ts
interface User { id: number }
interface User { name: string } // 선언 병합 → { id, name }

type Size = "S" | "M" | "L"; // 유니온 타입
```

### 3.4 유니온/교차와 타입 좁히기(narrowing)
```ts
type Payment =
  | { type: "cash"; amount: number }
  | { type: "card"; amount: number; last4: string };

function describePayment(p: Payment) {
  if (p.type === "card") {
    return `Card ****${p.last4} / ${p.amount}`;
  }
  // p는 여기서 cash로 좁혀짐
  return `Cash / ${p.amount}`;
}
```

## 4. 미니 실습: 동아리 회비 관리 미니 도메인
- 목표: 타입 안정성을 유지하며 미납자 목록과 총액을 계산하고, 안전한 업데이트 함수를 만든다.

```ts
// src/index.ts
type Member = {
  id: number;
  name: string;
  email?: string;
};

interface Dues {
  memberId: number;
  amount: number; // 원화
  paid: boolean;
}

const members: Member[] = [
  { id: 1, name: "Kim", email: "kim@club.com" },
  { id: 2, name: "Lee" },
  { id: 3, name: "Park" },
];

let dues: Dues[] = [
  { memberId: 1, amount: 10000, paid: true },
  { memberId: 2, amount: 15000, paid: false },
  { memberId: 3, amount: 15000, paid: false },
];

function unpaidMembers(members: Member[], dues: Dues[]): Member[] {
  const unpaidIds = new Set(dues.filter(d => !d.paid).map(d => d.memberId));
  return members.filter(m => unpaidIds.has(m.id));
}

function totalAmount(dues: Dues[]): number {
  return dues.reduce((sum, d) => sum + d.amount, 0);
}

// 안전한 업데이트: 존재 검증 + 불변성
function markPaid(duesList: Dues[], memberId: number): Dues[] {
  const idx = duesList.findIndex(d => d.memberId === memberId);
  if (idx === -1) throw new Error("존재하지 않는 memberId");
  const updated = [...duesList];
  updated[idx] = { ...updated[idx], paid: true };
  return updated;
}

console.log("미납자:", unpaidMembers(members, dues).map(m => m.name));
console.log("총액:", totalAmount(dues));

dues = markPaid(dues, 2);
console.log("2번 납부 처리 후 미납자:", unpaidMembers(members, dues).map(m => m.name));
```

실행
```bash
npm run dev
# 또는
npm run build && node dist/index.js
```

## 5. 트러블슈팅 메모
1) `any` 남용 지양: 빠르지만 타입 안전성 상실. 대신 `unknown` + 좁히기 사용.  
2) `Object is possibly 'undefined'`: `if (!x) return;` 같은 가드로 좁히기.  
3) Node ESM/CJS 혼동: Day1은 `"module": "CommonJS"`로 시작하면 간단.  
4) 서드파티 라이브러리 타입: `@types/패키지명` 설치 필요할 수 있음.
