# LangChain

## 📌 LangChain이란?
LangChain은 **LLM(대규모 언어 모델)을 활용한 애플리케이션을 쉽게 개발할 수 있도록 도와주는 프레임워크**입니다.  
단순히 프롬프트를 던지는 수준을 넘어, **외부 데이터/도구와 결합하여 체계적인 파이프라인(Chain)을 구축**할 수 있습니다.

---

## 🔎 핵심 개념
- **프롬프트 템플릿 (PromptTemplate)**  
  모델에게 보낼 입력을 구조화/템플릿화.

- **체인 (Chain)**  
  여러 단계를 연결해 하나의 워크플로로 구성.  
  예: 질문 → 문서 검색 → 답변 생성.

- **에이전트 (Agent)**  
  모델이 상황에 맞게 어떤 툴을 사용할지 스스로 결정.  
  (ReAct 패턴 기반: 추론 + 행동 반복)

- **도구 (Tool)**  
  외부 API, DB, 계산기 등을 연결해 모델이 활용 가능하게 만든 모듈.

- **메모리 (Memory)**  
  이전 대화 내용을 기억해 대화형 애플리케이션을 구현.

---

## ⚙️ 주요 구성 요소
- **LLM Wrapper**: OpenAI, Anthropic, Hugging Face 등 다양한 모델을 표준화된 인터페이스로 호출.  
- **PromptTemplate**: 입력 프롬프트를 유연하게 구성.  
- **Chains**: 여러 모듈을 연결한 파이프라인.  
- **Agents**: 상황에 따라 툴 선택/호출.  
- **Tools**: 검색 엔진, DB, API 같은 외부 리소스.  
- **Memory**: 대화 문맥 저장/재사용.

---

## 🔄 동작 흐름
1. **사용자 입력** → 질문/명령  
2. **PromptTemplate** → 입력 구조화  
3. **Chain/Agent** → 어떤 툴/경로로 처리할지 결정  
4. **Tool 호출** → 외부 API/DB 사용  
5. **LLM 응답 생성** → 사용자에게 결과 반환  

---

## 🧩 예시 (문서 QA 시스템)
- **구성**
  - PromptTemplate: `"주어진 문서를 참고해서 질문에 답해줘."`
  - Tool: 벡터DB(예: Pinecone, FAISS) 검색
  - Chain: (1) 질문 입력 → (2) 벡터 검색 → (3) 모델 답변

- **흐름**
사용자: "LangChain이 뭐야?"
↓
Agent: 문서 검색 툴 호출
↓
Tool: 관련 문서 스니펫 반환
↓
LLM: 스니펫 요약 + 답변 생성
↓
사용자에게 답변 전달

## 🛠️ 프로젝트 적용 시나리오
정현님의 프로젝트(🎤 음성 → 📄 요약 → 📓 Notion/Jira 기록)에 적용하면:

1. **STT 결과 → LangChain 입력**  
2. **Chain 구성**  
 - (1) 텍스트 요약 → (2) 액션 아이템 추출 → (3) Notion/Jira API 호출  
3. **Agent 활용**  
 - 모델이 상황에 따라 “요약만 할지”, “Jira 이슈도 생성할지” 판단  
4. **Memory**  
 - 이전 회의 내용과 연속된 맥락을 유지해 추적 가능

## ✅ MCP와 비교
| 항목 | MCP | LangChain |
|------|-----|-----------|
| 역할 | 모델 ↔ 외부 서비스 연결 표준 | LLM 기반 앱 프레임워크 |
| 초점 | **안전한 API 래핑** | **체인/에이전트/메모리 구조화** |
| 클라이언트 | Claude Desktop, 자체 클라이언트 | Python/JS SDK (개발자 코드 중심) |
| 서버 | 기능 제공자(API, DB 등) | 없음(외부 API/DB를 직접 사용) |
| 사용 방식 | “툴을 정의해두면 모델이 알아서 호출” | “개발자가 체인/에이전트로 조립 후 모델 실행” |

## ✅ 정리
- LangChain = **LLM 기반 앱 개발 프레임워크**  
- 제공 기능: PromptTemplate, Chains, Agents, Tools, Memory  
- 장점: 복잡한 LLM 워크플로를 모듈식으로 구현 가능  
- 프로젝트에선 **텍스트 요약/액션 아이템 추출/Notion/Jira 연동** 등을 체인으로 구성할 수 있음
