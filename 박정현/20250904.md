# 📱 Today I Learned: 하이브리드 앱(Hybrid App)

## 🔎 하이브리드 앱이란?
하이브리드 앱은 **웹 기술(HTML, CSS, JavaScript)**을 이용해 개발하고, 이를 **네이티브 앱의 WebView** 안에서 실행하는 방식의 앱을 말합니다.  

- **네이티브 앱**: iOS/Android 각각 전용 언어(Swift, Kotlin 등)로 개발  
- **웹 앱**: 브라우저에서만 동작 (설치 불필요)  
- **하이브리드 앱**: 웹 기술 + 네이티브 기능(API) 혼합  

즉, **한 번 개발 → 여러 플랫폼(iOS, Android)에 배포**할 수 있다는 장점이 있습니다.

---

## ⚙️ 구조
┌───────────────┐
│ 네이티브 껍데기 │ ← iOS/Android 앱 (WebView 포함)
└───────┬───────┘
│
┌───────▼───────┐
│ WebView │ ← 웹 페이지 로딩
└───────┬───────┘
│
┌───────▼────────┐
│ HTML / CSS / JS │ ← 우리가 작성하는 앱 로직(UI, 기능)
└─────────────────┘

---

## ✅ 장점
1. **크로스 플랫폼 개발**: 한 번의 코드로 iOS/Android 동시 지원  
2. **빠른 개발 속도**: 웹 기술만 알면 앱 제작 가능  
3. **업데이트 용이**: 앱스토어 심사 없이 서버에서 웹 자원 교체 가능  
4. **비용 절감**: 별도의 네이티브 개발팀이 없어도 됨  

---

## ⚠️ 단점
1. **성능 이슈**: 네이티브 앱보다 느릴 수 있음 (특히 애니메이션/고성능 게임)  
2. **네이티브 기능 제약**: 카메라, 센서, 푸시 알림 등은 별도 플러그인 필요  
3. **UI/UX 한계**: 플랫폼별 네이티브 UI를 완전히 똑같이 구현하기 어려움  

---

## 🛠️ 대표 프레임워크
- **Apache Cordova / PhoneGap**: 오래된 하이브리드 앱 프레임워크  
- **Ionic**: Angular, React, Vue와 연동 가능. UI 컴포넌트 풍부  
- **Capacitor** (Ionic 팀 제작): 최신 하이브리드 솔루션, 플러그인 확장성 높음  
- **Flutter**: Dart 기반, 네이티브 렌더링. 하이브리드보단 크로스 플랫폼 앱 범주에 가까움  

---

## 💡 오늘 배운 포인트
- 하이브리드 앱은 **웹 기술을 WebView 안에서 실행하는 앱**이다.  
- 네이티브와 웹의 장단점을 절충한 형태 → 빠른 개발과 크로스 플랫폼에 강점.  
- 성능·네이티브 기능 접근에 한계가 있어, 프로젝트 성격에 따라 선택이 중요하다.  

---

## ✨ 정리
- 하이브리드 앱 = **웹 + 네이티브 껍데기**  
- 장점: 빠른 개발, 크로스 플랫폼, 저비용  
- 단점: 성능, 네이티브 기능 제약  
- Ionic, Capacitor, Cordova 같은 프레임워크 활용 가능
