# SSAFY 과제

## FCM 개념

- **Firebase Cloud Messaging**은 Google Firebase에서 제공하는 무료 크로스 플랫폼 메시징 서비스입니다.
- 서버에서 클라이언트(모바일 앱, 웹 앱 등)로 푸시 알림이나 데이터 메시지를 안정적으로 전송할 수 있는 솔루션입니다.
- Android, iOS, 웹 등 다양한 플랫폼을 지원하며, 단일 기기, 기기 그룹, 주제 구독자 등으로 메시지를 타겟팅할 수 있습니다.

---

## FCM 주요 기능

- 알림 메시지(Notification Message): 클라이언트에서 자동으로 알림을 표시
- 데이터 메시지(Data Message): 앱에서 직접 처리 가능한 커스텀 데이터 전달
- 높은 안정성, 다양한 전송 옵션 및 유연한 타겟팅
- 자동 재전송 및 오프라인 상태 메시지 보관 기능

---

## 장점

- **무료 제공**: 비용 부담 없이 안정적인 메시지 전송 가능
- **크로스 플랫폼 지원**: Android, iOS, 웹 등 다양한 환경에서 사용 가능
- **확장성**: 대규모 사용자에게 효율적으로 메시지 전송 가능
- **간편한 연동**: Firebase 플랫폼과의 연동이 직관적이고 쉬움
- **안정적인 전송**: 재시도, 오프라인 보관, 플랫폼별 전송 최적화 지원

---

## 단점

- **의존성**: Google Firebase 플랫폼에 의존해 자체 인프라 구축 제한
- **메시지 제한**: 메시지 크기(최대 4,000바이트)와 빈도 제한 존재
- **맞춤 처리 복잡성**: 데이터 메시지 처리 시 클라이언트 사이드 구현 부담
- **플랫폼별 제한**: iOS에서는 APNs 규칙 등에 따른 별도 제약 가능

---

## 사용처

- 모바일 앱에서 사용자 맞춤 푸시 알림 제공(이벤트, 프로모션, 긴급 알림 등)
- 웹 앱에서 실시간 알림 또는 데이터 푸시
- 채팅 앱, 소셜 네트워크, 뉴스 앱 등 실시간 메시징 필요 서비스
- 사용자 행동 유도, 리텐션 강화, 마케팅 메시지 전달
- 클라우드 기반 서버에서 사용자 단말로 비동기 이벤트 신호 전달

---

FCM은 안정적이고 무료이며 다양한 플랫폼을 지원해서 최근 모바일·웹 푸시 알림 서비스에 널리 사용되고 있습니다.
