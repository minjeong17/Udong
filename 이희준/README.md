# AI 스터디 요약

이 저장소는 AI 관련 기술인 MCP와 LangChain에 대한 학습 내용을 요약합니다.

<details>
<summary><strong>1일차: MCP (Model Context Protocol) 요약</strong></summary>

### MCP란?
MCP(Model Context Protocol)는 AI 모델이 외부 데이터, 도구, 시스템과 안전하고 일관되게 연결될 수 있도록 하는 개방형 표준 프로토콜입니다. "AI용 USB-C 포트"처럼, 각기 다른 AI 모델과 도구들을 하나의 표준으로 연결하여 복잡한 통합 문제를 해결합니다.

### 핵심 특징
- **표준화**: 모든 AI 모델이 동일한 방식으로 외부 시스템과 통신합니다.
- **개방성**: 오픈소스로 누구나 사용하고 기여할 수 있습니다.
- **보안성**: 안전한 데이터 교환을 위한 프로토콜이 내장되어 있습니다.
- **확장성**: 새로운 도구와 데이터 소스를 쉽게 추가할 수 있습니다.

### 주요 구성 요소
- **MCP Host**: AI 모델을 내장한 애플리케이션 (예: Claude Desktop, VS Code 확장).
- **MCP Client**: 호스트 내부에서 서버와의 통신을 담당합니다.
- **MCP Server**: 실제 데이터나 기능을 제공하는 프로그램 (데이터베이스, API 등).
- **Transport Layer**: 클라이언트와 서버 간의 통신 방식을 정의합니다 (STDIO, HTTP/SSE 등).

### 활용 사례
- **지능형 코딩 어시스턴트**: 실시간 코드 분석, 테스트 실행, 디버깅을 수행합니다.
- **기업용 AI 어시스턴트**: 사내 문서 검색, CRM 데이터 조회, 일정 관리를 자동화합니다.
- **데이터 분석 자동화**: 자연어로 데이터베이스를 쿼리하고 보고서를 생성합니다.

MCP는 AI가 가진 정보의 시간적 한계, 접근 권한의 제약, 실행 능력의 부재와 같은 근본적인 문제들을 해결하며, AI 생태계의 중요한 연결 표준으로 자리 잡고 있습니다.

<summary><strong>2일차: LangChain 요약</strong></summary>

### LangChain이란?
LangChain은 대규모 언어 모델(LLM)을 활용한 애플리케이션 개발을 간소화하는 오픈소스 프레임워크입니다. LLM을 레고 블록에 비유한다면, LangChain은 이 블록들을 조립하여 실제 유용한 결과물을 만들 수 있도록 돕는 '설명서와 특수 부품 세트'와 같습니다.

### 핵심 특징
- **모듈화**: 필요한 기능을 블록처럼 조합하여 사용할 수 있습니다.
- **유연성**: OpenAI, Claude, Google AI 등 다양한 LLM을 지원합니다.
- **확장성**: 외부 도구(API, 데이터베이스)와 쉽게 연결할 수 있습니다.
- **개발 편의성**: 복잡한 AI 워크플로우를 간단한 코드로 구현할 수 있습니다.

### 주요 구성 요소
- **Models**: 다양한 언어 모델과 상호작용하는 통일된 인터페이스를 제공합니다.
- **Prompts**: AI에 전달할 지시사항을 체계적으로 관리하는 템플릿입니다.
- **Chains**: 여러 작업을 연결하여 복잡한 워크플로우를 구성합니다.
- **Memory**: 대화의 맥락과 정보를 저장하고 관리하여 '기억'을 구현합니다.
- **Indexes**: 외부 문서를 불러와 구조화하고 검색 가능하게 만듭니다.
- **Agents**: 스스로 판단하고 계획을 세워 도구를 사용하는 자율적인 시스템입니다.

### 활용 사례
- **고객 서비스 챗봇**: 회사 매뉴얼을 기반으로 고객 문의에 답변합니다.
- **문서 요약 및 분석**: 긴 보고서를 자동으로 요약하고 핵심 정보를 추출합니다.
- **코드 리뷰 도우미**: 코드 변경사항을 분석하고 잠재적 버그를 탐지합니다.

LangChain은 LLM의 한계(컨텍스트 제한, 최신 정보 부족, 실행 능력 부재 등)를 극복하고, 개발자가 더욱 강력하고 실용적인 AI 애플리케e이션을 만들 수 있도록 지원하는 핵심적인 프레임워크입니다.

</details>

<summary><strong>3일차: 데이터베이스 정규화, 반정규화, 인덱스 요약</strong></summary>

### 정규화(Normalization)란?
데이터베이스에서 중복을 최소화하고 데이터 무결성을 보장하기 위해 테이블을 체계적으로 분해하는 과정입니다. 정리되지 않은 옷장을 종류별로 분류하고 중복을 제거하는 것처럼, 데이터를 논리적으로 구조화합니다.

### 정규화 단계
- **1NF(제1정규형)**: 각 컬럼은 하나의 원자값만 가져야 합니다.
- **2NF(제2정규형)**: 부분 종속을 제거하여 기본키 전체에 종속되도록 합니다.
- **3NF(제3정규형)**: 이행적 종속을 제거하여 기본키에만 직접 종속되도록 합니다.
- **BCNF**: 모든 결정자가 후보키여야 합니다.

### 반정규화(Denormalization)란?
조회 성능 향상을 위해 정규화된 데이터베이스에 의도적으로 중복을 추가하는 기법입니다. 정규화와 성능 사이의 전략적 타협점을 찾는 과정입니다.

### 반정규화 기법
- **계산된 컬럼 추가**: 자주 계산되는 값을 미리 저장합니다.
- **중복 컬럼 추가**: 조인을 줄이기 위해 자주 사용되는 데이터를 복사합니다.
- **테이블 통합**: 1:1 관계의 테이블을 하나로 합칩니다.
- **요약 테이블 생성**: 집계 데이터를 별도 테이블로 관리합니다.

### 인덱스(Index)란?
데이터베이스 테이블의 검색 속도를 향상시키는 자료구조로, 책의 색인과 같은 역할을 합니다.

### 인덱스 유형
- **클러스터링 인덱스**: 실제 데이터가 인덱스 순서대로 물리적으로 정렬됩니다. 전화번호부처럼 한 가지 순서로만 정렬 가능하며, 테이블당 하나만 생성할 수 있습니다.
- **논클러스터링 인덱스**: 실제 데이터와 별도로 인덱스 구조를 생성합니다. 책 뒤의 색인처럼 여러 개를 생성할 수 있으며, 다양한 검색 패턴을 지원합니다.

### 핵심 원칙
- 먼저 정규화로 데이터 무결성을 확보한 후, 성능 문제가 있을 때만 반정규화를 고려합니다.
- 인덱스는 만능이 아니며, 워크로드에 맞는 설계가 중요합니다.
- "측정 없는 최적화는 추측일 뿐" - 항상 성능을 측정하고 개선해야 합니다.

<summary><strong>4일차: React + TypeScript + Tailwind CSS 요약</strong></summary>

### React란?
Facebook(Meta)에서 만든 사용자 인터페이스 구축용 JavaScript 라이브러리입니다. 레고 블록처럼 작은 컴포넌트들을 조립하여 복잡한 UI를 만들 수 있으며, 컴포넌트의 재사용성이 핵심입니다.

### React 핵심 개념
- **컴포넌트(Component)**: 재사용 가능한 UI 조각입니다.
- **JSX**: JavaScript 안에서 HTML을 작성하는 문법입니다.
- **State**: 컴포넌트가 가지는 변경 가능한 데이터입니다.
- **Props**: 부모 컴포넌트에서 자식에게 전달하는 데이터입니다.
- **Hooks**: 함수형 컴포넌트에서 상태와 생명주기를 사용하게 해주는 기능입니다.

### TypeScript란?
JavaScript에 타입 시스템을 추가한 언어로, 코드를 더 안전하고 예측 가능하게 만들어줍니다. 교통 신호등처럼 코드의 안전성을 보장하며, 실행 전에 오류를 미리 발견할 수 있습니다.

### TypeScript 핵심 기능
- **타입 정의**: 변수, 함수, 객체의 타입을 명시적으로 지정합니다.
- **인터페이스**: 객체의 형태를 정의하여 일관성을 보장합니다.
- **제네릭**: 타입을 변수처럼 사용하여 재사용 가능한 컴포넌트를 만듭니다.
- **타입 추론**: 명시적 타입 선언 없이도 타입을 자동으로 파악합니다.

### Tailwind CSS란?
HTML을 떠나지 않고도 빠르게 스타일링할 수 있는 유틸리티 우선 CSS 프레임워크입니다. 미리 만들어진 스티커 세트처럼, 필요한 유틸리티 클래스를 조합하여 디자인을 완성합니다.

### Tailwind 주요 특징
- **유틸리티 클래스**: `p-4`, `text-center`, `bg-blue-500` 같은 단일 목적 클래스를 제공합니다.
- **반응형 디자인**: `md:`, `lg:` 같은 접두사로 화면 크기별 스타일을 적용합니다.
- **일관된 디자인 시스템**: 미리 정의된 스케일로 일관성 있는 UI를 구축합니다.
- **빠른 개발**: CSS 파일을 작성하지 않고도 복잡한 디자인을 구현할 수 있습니다.

### 시너지 효과
- **React**: 컴포넌트 기반으로 UI의 구조를 만듭니다.
- **TypeScript**: 타입 체크로 버그를 사전에 방지합니다.
- **Tailwind**: 빠르고 일관성 있는 스타일링을 제공합니다.

이 세 가지를 함께 사용하면 빠르고, 안전하고, 아름다운 모던 웹 애플리케이션을 효율적으로 개발할 수 있습니다.

</details>

<summary><strong>5일차: React 생태계 필수 라이브러리 요약</strong></summary>

### React 생태계란?
React 개발을 더욱 효율적으로 만들어주는 검증된 라이브러리들의 모음입니다. "바퀴를 다시 발명하지 말라"는 격언처럼, 이미 잘 만들어진 도구들을 활용하여 개발 생산성과 코드 품질을 획기적으로 향상시킬 수 있습니다.

### 1. 상태 관리 라이브러리

#### Zustand
- **특징**: Redux의 복잡함 없이 간단하게 전역 상태를 관리할 수 있는 가장 인기 있는 라이브러리
- **장점**: 보일러플레이트 코드가 거의 없고, TypeScript 지원이 우수하며, devtools와 persist 미들웨어 제공
- **사용 시기**: 중소규모 프로젝트에서 간단한 전역 상태 관리가 필요할 때

#### Jotai
- **특징**: React의 useState처럼 사용하면서도 전역 상태를 관리하는 원자적(Atomic) 접근 방식
- **장점**: React Suspense 지원, 파생 상태 자동 계산, 비동기 atom 지원
- **사용 시기**: 컴포넌트 간 상태 공유가 필요하지만 중앙 집중식 스토어를 원하지 않을 때

#### Redux Toolkit
- **특징**: Redux의 공식 도구 모음으로 복잡성을 크게 개선
- **장점**: 예측 가능한 상태 관리, 시간 여행 디버깅, 대규모 앱에서 검증된 패턴
- **사용 시기**: 대규모 엔터프라이즈 애플리케이션 개발 시

### 2. 데이터 페칭 라이브러리

#### TanStack Query (React Query)
- **특징**: 서버 상태를 캐싱, 동기화, 업데이트하는 강력한 데이터 페칭 라이브러리
- **장점**: 자동 캐싱, 백그라운드 리페칭, 무한 스크롤 지원, 낙관적 업데이트
- **사용 시기**: REST API나 GraphQL과 통신하는 모든 프로젝트

#### SWR
- **특징**: Vercel이 만든 "Stale-While-Revalidate" 전략 기반 경량 데이터 페칭
- **장점**: 간단한 API, 실시간 데이터 동기화, Next.js와 완벽 호환
- **사용 시기**: Next.js 프로젝트나 간단한 데이터 페칭이 필요할 때

### 3. 폼 관리 라이브러리

#### React Hook Form
- **특징**: 최소한의 리렌더링으로 고성능 폼을 구현하는 라이브러리
- **장점**: 뛰어난 성능, 작은 번들 크기, Zod/Yup 등 스키마 검증 통합
- **사용 시기**: 복잡한 폼이나 많은 입력 필드가 있는 경우

### 4. UI 컴포넌트 라이브러리

#### Radix UI
- **특징**: 스타일 없이 접근성과 기능만 제공하는 헤드리스 컴포넌트
- **장점**: 완벽한 접근성 지원, 커스터마이징 자유도, Tailwind와 완벽 호환
- **사용 시기**: 디자인 시스템을 직접 구축하거나 완전한 스타일 제어가 필요할 때

#### Headless UI
- **특징**: Tailwind CSS 팀이 만든 완전히 스타일링 가능한 UI 컴포넌트
- **장점**: Tailwind와 완벽 통합, 가벼운 번들 크기, 간단한 API
- **사용 시기**: Tailwind CSS를 사용하는 프로젝트

### 5. 애니메이션 라이브러리

#### Framer Motion
- **특징**: 선언적 API로 복잡한 애니메이션을 쉽게 구현
- **장점**: 제스처 지원, 드래그 앤 드롭, SVG 애니메이션, 레이아웃 애니메이션
- **사용 시기**: 풍부한 인터랙션과 애니메이션이 필요한 프로젝트

### 6. 유틸리티 라이브러리

#### React Hot Toast
- **특징**: 아름답고 가벼운 토스트 알림 라이브러리
- **장점**: 설정 없이 바로 사용, Promise 기반 알림, 완전한 커스터마이징
- **사용 시기**: 사용자 피드백 알림이 필요한 모든 프로젝트

#### React DnD
- **특징**: 복잡한 드래그 앤 드롭 인터페이스 구현
- **장점**: 터치 지원, 키보드 접근성, 다양한 백엔드 지원
- **사용 시기**: 칸반 보드, 리스트 재정렬 등 드래그 기능이 필요할 때

### 7. 테이블 라이브러리

#### TanStack Table
- **특징**: 강력하고 확장 가능한 헤드리스 테이블 라이브러리
- **장점**: 정렬, 필터링, 페이지네이션, 가상화 지원, 완전한 TypeScript 지원
- **사용 시기**: 복잡한 데이터 테이블이나 그리드가 필요할 때

### 권장 스타터 킷
