## 핀테크(FinTech)

### 1. 핀테크란?
- IT 기술(모바일, 클라우드, AI, 블록체인 등)을 활용해 금융 서비스를 혁신하는 산업
- 기존 금융회사가 제공하던 서비스를 **더 편리하고 저렴하게** 제공하거나,  
  기존에 없던 새로운 금융 경험을 만들어내는 것이 핵심

### 2. 주요 서비스 영역
1. **결제/송금**
   - 간편결제 (카카오페이, 네이버페이, 토스)
   - 해외 송금 (와이어바알리, 페이팔)
2. **자산관리/투자**
   - 로보어드바이저 (AI 기반 투자 추천)
   - 주식·코인 거래 플랫폼
3. **대출/크라우드펀딩**
   - P2P 대출 플랫폼
   - 스타트업·프로젝트 펀딩
4. **보험(InsurTech)**
   - 맞춤형 보험 추천, 보험 청구 간소화
5. **보안·인증**
   - 생체인증, 블록체인 기반 신원 확인

### 3. 활용 기술
- **AI/머신러닝** → 신용평가, 사기 탐지, 투자 추천
- **블록체인** → 암호화폐, 스마트 계약, 거래 투명성 확보
- **빅데이터** → 소비 패턴 분석, 맞춤 금융상품 추천
- **클라우드/오픈API** → 은행/카드사 데이터 개방(Open Banking)

### 4. 장점과 한계
- **장점**
  - 금융 접근성 확대 (언뱅크드 계층까지 포함)
  - 빠르고 간편한 서비스 제공
  - 데이터 기반 맞춤형 금융 서비스
- **한계/리스크**
  - 개인정보·보안 문제
  - 규제 미비 → 금융사기, 불법 거래 위험
  - 기존 금융기관과의 마찰

### 정리
- 핀테크 = **금융 + 기술**을 통해 금융 서비스를 혁신하는 산업
- 결제, 투자, 보험, 대출 등 다양한 분야에서 이미 일상화
- 기술 혁신과 함께 규제·보안·윤리 문제도 중요
