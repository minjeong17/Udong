## LangChain

### 1. LangChain이란?
- LLM을 기반으로 하는 애플리케이션을 만들기 위한 **Python/JS 라이브러리**
- 주요 목표: "LLM을 단순히 API로 호출하는 것 → 실제 서비스 로직과 연결"
- 장점: 데이터 소스, API, 데이터베이스 등과 쉽게 연계 가능

### 2. 주요 기능
1. **프롬프트 관리**
   - 여러 프롬프트 템플릿을 만들어 재사용 가능
   - 변수를 넣어 동적으로 프롬프트 생성

2. **체인(Chain)**
   - 여러 LLM 호출 또는 기능들을 순차적으로 연결
   - 예: 질문 입력 → 문서 검색 → 요약 → 답변 생성

3. **에이전트(Agent)**
   - LLM이 스스로 어떤 도구(API, DB, 계산기 등)를 쓸지 결정
   - 예: "오늘 날씨 알려줘" → LLM이 날씨 API 호출 → 결과를 기반으로 대답

4. **메모리(Memory)**
   - 대화 기록이나 이전 상태를 기억
   - 챗봇처럼 맥락 있는 대화를 이어갈 수 있게 해줌

### 3. 활용 예시
- **문서 QA 시스템**: PDF 업로드 → 벡터DB에 임베딩 저장 → 사용자가 질문하면 관련 부분 검색 후 LLM 답변
- **데이터 분석 챗봇**: LLM이 SQL 쿼리를 자동 생성해서 DB 질의
- **멀티툴 에이전트**: LLM이 웹 검색, 계산기, API 호출 등을 스스로 선택해 답변 생성

### 정리
- LangChain = **LLM 앱 개발을 위한 프레임워크**
- 단순 API 호출 → **프롬프트 관리 + 체인 + 메모리 + 에이전트**로 확장
- 실제 서비스에서 LLM을 쓸 때 필요한 **구조화된 워크플로우**를 제공해준다
