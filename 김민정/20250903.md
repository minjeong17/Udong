## MCP (Model Context Protocol)

### 한 줄 정의
: MCP는 LLM이 외부의 도구·데이터와 표준 방식으로 통신하도록 하는 오픈 프로토콜

### 왜 MCP인가

- 표준화·호환성: 한 번 만든 도구(서버)를 여러 LLM/클라이언트에서 재사용할 수 있게 해줍니다. 
- 보안 경계 분리: API 키·내부 시스템 접근은 MCP 서버에 두고, 챗앱은 허용된 툴만 호출합니다. 
- OpenAI 공식 지원: Responses API가 원격 MCP 서버 연결을 지원합니다(허용 툴 목록으로 제어). 

### 구성 요소

- Tools: 실행 가능한 기능(예: 장소 검색, 결제 처리 트리거).
- Resources: 읽기 전용 데이터(파일, DB, HTTP 등).
- Prompts: 재사용 가능한 프롬프트 템플릿.

### 통신 방식(Transport)

- STDIO: 로컬 프로세스로 빠르게 연결
- HTTP(SSE): 원격 서버와 스트리밍 대응

### OpenAI에서의 사용

- ChatGPT 커넥터: 커스텀 커넥터(MCP) 추가로 사내/서드파티 시스템을 연결할 수 있습니다.
- Responses API: 백엔드에서 원격 MCP 서버를 붙여 모델이 툴을 발견 → 허용(allowed_tools) → 호출하도록 구성합니다. 

### 언제 쓰면 좋은가

- 외부 API·사내 시스템에 검색/조회/집계/실행을 맡길 때
- 예: "원하는 지역 입력 → 엠티 장소 검색·상세 조회·단체 적합도 정렬 → 요약" 같은 파이프라인을 툴로 묶어 자동화
